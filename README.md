# engine-ui

Panel básico de telemetría para un motor de cohete, hecho con Rust y [Slint](https://docs.slint.dev/latest/docs/slint/).

La interfaz muestra indicadores de presión, empuje, temperatura y turbobomba, una tendencia de presión de muestra, estado de subsistemas y un registro de eventos. Los datos son simulados y no están conectados a hardware.

## Ejecutar

```sh
cargo run
```
